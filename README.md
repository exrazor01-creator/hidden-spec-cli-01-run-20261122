mend is one command-line tool that applies the edits AI models write, in four formats (unified diffs with wrong line numbers, SEARCH/REPLACE blocks, V4A patches and JSON tool calls), to a tree of text files — finding the lines each edit names even when the model drifted their whitespace or indentation, and changing every file or none.

## Run it

```sh
node main.ts [options] [PATCH]
```
